Normalized positional similarity over displacement

C(r) = mean cos(r × frequency / scale), for integer lags 0–512. C is even, so positive and negative displacements have the same kernel. The marker appears when the selected absolute lag is in this range. Oscillations and repeated peaks are visible; this is not a monotonic decay law.

These plots describe deterministic position geometry, not learned attention. C is neither a probability nor a complete model score. A causal model would additionally forbid keys after the query.
